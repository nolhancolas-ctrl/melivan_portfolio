Melivan — Motion Design Portfolio
A creative showcase built around movement, imagery and visual storytelling.

Melivan is a portfolio project centered on presenting motion design work with a clear, expressive visual identity. The idea is to make the work itself the main character: bold presentation, intentional pacing and space for each project to stand out.
This project is also a collaboration between two brothers — one shaping the creative direction, the other translating that vision into a web experience.

Project vision

Work first: let motion pieces and selected projects lead the experience.
Distinctive identity: carry the creator's visual language through the interface.
Purposeful motion: use transitions to guide attention rather than simply decorate.
Clear navigation: make it easy to explore projects and get in touch.
